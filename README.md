# Виктор Тестов — Сайт-визитка

Персональный сайт-визитка специалиста по изготовлению мебели, компании ZALEPILOF.

## О проекте

Одностраничный лендинг (landing page), демонстрирующий профессиональные навыки, портфолио работ и контактную информацию мастера по мебели.

## Структура проекта

```
📁 workspace/
  📄 index.html          # Главная страница
  📁 css/
    📄 style.css         # Стили
  📁 js/
    📄 script.js         # JavaScript-логика
  📁 img/
    📁 avatar/           # Фото специалиста
    📁 portfolio/        # Примеры работ
```

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — стилизация и адаптивный дизайн
- **JavaScript** — интерактивность (галерея портфолио)

## Секции сайта

1. **Hero Section** — фото и представление специалиста
2. **Услуги** — описание деятельности и галерея портфолио
3. **Преимущества** — почему выбирают мастера
4. **Контакты** — телефон и email

## Запуск

Откройте `index.html` в браузере.

## Технологии

- Чистый HTML/CSS/JS без фреймворков
